# Sistem Rekening Bank Java

Program sederhana Sistem Rekening Bank menggunakan bahasa Java.

## Deskripsi

Program ini dibuat untuk menerapkan konsep dasar Object-Oriented Programming `(OOP)`, khususnya:

- Enkapsulasi
- Constructor
- Getter dan Setter
- Static Variable
- Validasi
- Method dan Object

Program dapat membuat rekening, melihat saldo, melakukan transfer, dan menghitung jumlah rekening yang dibuat.

## Fitur

- Membuat rekening baru
- Menyimpan nomor rekening dan nama pemilik
- Validasi saldo awal minimal Rp50.000
- Melihat saldo menggunakan Getter
- Mengubah saldo menggunakan Setter
- Transfer antar rekening
- Menolak transfer jika saldo tidak mencukupi
- Menghitung total rekening menggunakan `static`
